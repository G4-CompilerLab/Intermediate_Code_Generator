ABOUT THE PROJECT

Intermediate Code Generator (Three Address Code)

This Compiler Design Lab project demonstrates how a source program can be transformed into an intermediate representation before the later stages of code generation. The user enters a C-like program, and the application presents the important intermediate-analysis results in a clear, visual sequence.

The workflow begins with lexical analysis, where the source is broken into tokens such as keywords, identifiers, constants, operators, and separators. The identified identifiers and their basic information are organized in a symbol table. The system then generates Three Address Code (TAC), an intermediate representation in which complex expressions are divided into simple instructions using temporary variables. The same TAC is also represented as quadruples and triples to show different ways of storing intermediate instructions.
